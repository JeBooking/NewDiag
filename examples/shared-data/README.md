# 共享报告示例

1. 工程管理登记「共享报告示例」，路径填写本目录绝对路径，模块 shared_report，工厂留空。
2. 导入 workflow.json，保存、发布后启动。默认读取本目录 report.json。
3. 控制台中「获取报告路径」「解析报告一次」各出现一次。电压、电流排查分别使用 voltage、current。
4. 两个排查的运行记录 output.data 应引用同一产物；判断依据分别为 225 对比 230、12 对比 10。

数据准备节点可放到所需分支中；下游选择「使用数据准备结果」，再配置展示和判断字段。
人工判断或回退行为见 docs/module-integration.md 的「共享获取与解析」。

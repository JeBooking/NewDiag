# 普通工程组合接入示例

两个业务工程都不导入平台 SDK，不继承 Diagnosis，返回普通 Python 数据或自己的业务类。

完整操作见[用户手册](../../docs/user-manual.md)，模块接口与原理见[开发者手册](../../docs/developer-manual.md)。

| 文件 | 用途 |
|---|---|
| `data_tools/records.py` | 普通 Dataset 类，接受数组或解析 JSON 文件，生成曲线 |
| `analysis_tools/checks.py` | 普通判断工厂与类，返回 Verdict 对象 |
| `workflow.json` | 启动加载固定资源，展示曲线，自动／人工判断及现场参数 |
| `workflow-lazy.json` | 首次使用时加载资源 |
| `workflow-upload.json` | 启动上传文件，由原方法按路径解析 |
| `samples.json` | 上传示例 `[1,2,8,3]` |

1. 登记 `组合数据示例`，目录为本例 `data_tools` 的绝对路径，模块 `records`，工厂留空。
2. 登记 `组合判断示例`，目录为 `analysis_tools` 的绝对路径，模块 `checks`，工厂留空。
3. 解释器使用可运行这些普通 Python 文件的环境，无第三方依赖。
4. 导入 `workflow.json`、保存并发布，使用默认输入启动。
5. 处理人工动作与判断；最后一个节点现场填写倍率，例如 `1`。

预期：默认倍率 `1` 时峰值为 `8`，阈值为 `5`，自动判断为“是”；最后现场填写 `0.5` 时峰值为 `4`，判断为“否”。最后现场检查的两个出口都通向结束节点。

流程属性中的“组合现有工程”可查看普通工厂、固定资源、有序调用、图表与判断字段映射。曲线数据跨工程传递，Dataset 与 Verdict 对象分别保留在各自工程内。

`workflow-lazy.json` 把资源改为首次使用时加载。`workflow-upload.json` 从平台上传文件，使用本例 `samples.json`，原方法直接接收本地文件路径。

启动时选择串行或并行及数量上限；这些设置不保存到流程定义。当前示例主链为串行依赖，需要并行时可以在画布同一出口添加多个同级排查节点。

回退验证入口：在人工确认处选择已完成的“首次检查”，重新选择其后继。目标节点及已有人工结果应复用，不重新执行。固定资源继续复用，普通可变对象恢复到目标到访。

以上是使用及手工验证步骤，需求开发阶段未执行这些流程或浏览器验收。

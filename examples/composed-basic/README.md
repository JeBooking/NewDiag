# 普通工程槽位接入示例

两个业务工程都不导入平台 SDK，不继承基类，返回普通 Python 数据或自己的业务类。

完整操作见[用户手册](../../docs/user-manual.md)，模块接口与原理见[开发者手册](../../docs/developer-manual.md)。

| 文件 | 用途 |
|---|---|
| `data_tools/records.py` | 普通 Dataset 类，接受数组，按倍率生成曲线 |
| `analysis_tools/checks.py` | 普通判断工厂与类，返回 Verdict；`check` 返回 `{result, reason}` |
| `workflow.json` | 构造两个对象，覆盖自动判定、人工判断、现场参数三种节点 |
| `samples.json` | 上传示例 `[1,2,8,3]`，供自定义流程使用 |

1. 登记 `组合数据示例`，目录为本例 `data_tools` 的绝对路径，模块 `records`。
2. 登记 `组合判断示例`，目录为 `analysis_tools` 的绝对路径，模块 `checks`。
3. 解释器使用可运行这些普通 Python 文件的环境，无第三方依赖。
4. 导入 `workflow.json`、保存并发布，使用默认输入启动。
5. 第一个节点自动判定；第二个节点在待办里看曲线选是／否；第三个节点现场填写倍率，例如 `1`。

预期：默认倍率 `1` 时峰值为 `8`、阈值 `5`，自动判断为「是」；现场填 `0.5` 时峰值为 `4`，判断为「否」。两个出口都通向结束节点。

示例里的三个排查节点分别演示：

- 拉取 + 展示 + 自动判定（`Dataset.series` + `ThresholdRules.check`）
- 只展示 + 人工判断
- 现场参数驱动的拉取（`scale` 来自现场填写）+ 自动判定

启动时选择串行或并行及数量上限；这些设置不保存到流程定义。示例主链是顺序依赖，需要并行时在同一出口加多个同级排查节点。

回退验证入口：在人工判断处选择已完成的「看曲线并判定峰值」，重新选择后继；目标节点与已有人工结果复用，不重新执行，已取到的数据继续保留。

以上是使用及手工验证步骤，浏览器交互尚未逐项手工验收。

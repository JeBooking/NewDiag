# 共享数据准备交付

新增「数据准备」节点：在指定位置获取、解析一次，多个下游排查引用同一次准备的结果。
排查属性的「数据来源」选择「使用数据准备结果」，选择准备节点；展示、判断参数按字段路径取值。
准备节点可有多个默认后继；数据引用不会触发额外调度。

共享数据保存在实例隔离的不可变产物中，按字段偏移读取。运行记录与待办只保存引用。
人工等待和跨工程调用不会丢失产物；重跑判断沿用祖先准备结果，重跑准备生成新版本。
旧函数模式、旧四阶段节点及上游字段参数绑定继续兼容。

## 运行边界

产物需随 backend/data 备份，暂不自动回收。显式请求整个结果仍需加载整个结果。
超时或进程崩溃的重试可能再次调用准备函数，因此函数继续要求只读且可重复调用。

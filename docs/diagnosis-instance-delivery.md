# 诊断实例类交付

一张流程绑定一个业务类，一次诊断创建一个逻辑对象。initialize 首次启动准备主要数据，
排查节点选择实例方法；@resource 包住按需获取和解析，同请求首次加载后缓存。
人工等待保存业务对象和缓存引用，关闭进程；继续时从整体快照恢复普通成员，不再执行构造器或初始化。
旧函数、四阶段适配器、四阶段函数配置及共享准备节点保持兼容，旧流程无需迁移。

## 运行边界

当前 v1.12 按普通 Python 写法使用 self.report 等成员，对象整体快照，默认全部恢复。
按需资源由 @resource 管理，恢复不重跑 __init__ 或 initialize；普通成员更新也随到访保存。
恢复范围及运行资源应如何排除或重建，按用户要求暂留 docs/todo.md，不在本轮设计选择清单。
资源输入必须明确设备、文件身份、业务时间、解析参数等；处置不隐式刷新数据。
产物随 backend/data 备份，缺失或损坏时报错，暂不自动回收。不增加平台重启自动续跑能力，
超时或崩溃的重试仍可能再次调用业务接口，不承诺跨故障严格只执行一次。

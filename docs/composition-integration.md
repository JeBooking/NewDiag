# 通用 Python 工程组合接入

平台配置对象、资源和操作，并生成 Python 执行。模块维护者提供普通公开接口；流程编排者在界面选择接口和参数来源，无需新建总控诊断类或继承 Diagnosis。

本页为接入速查。完整操作见[用户手册](user-manual.md)，模块协议、状态保存和平台扩展见[开发者手册](developer-manual.md)。

## 接入步骤

1. 在工程页登记原工程目录、默认模块、解释器。安装原工程需要的依赖；组合模式的工厂留空，改在流程中配置构造器或工厂参数。
2. 新建流程，流程属性默认为“组合现有工程”。已有流程可选择该方式；切换模式会清理不兼容的节点绑定，可通过编辑器撤销恢复。
3. “实例对象”配置需要保留状态的普通对象：选工程、模块、接口和参数来源。支持构造器、工厂，以及已有对象方法返回的新对象。对象首次使用时创建。
4. “固定资源”配置取数和解析的有序调用，指定最终结果、启动加载或按需加载。同资源及同请求参数只获取一次；原方法不必改用 Data。
5. “排查操作”配置调用顺序。选择“已有对象的方法”后指定调用目标和公开方法；参数可以来自启动输入、操作参数、此前调用、对象、资源、上游节点或平台输出路径，也可组合列表／字典。
6. 选择返回类型：结构化数据、业务对象、文件或图片。原有自定义对象留在所属工程；通过公开属性路径或方法返回结构化值后可交给其他工程。
7. 配置展示映射：折线接数值数组，指标接 `{label,value,unit?}` 列表，表格接 `{columns,rows}`，文字接字符串或 JSON，图片接图片输出。自动判断选择布尔／yes-no 字段和依据；不配置则等待人工判断。
8. 排查节点选择操作。操作参数可配置来源，或勾选现场填写并选择输入类型。启动文件参数应选择“将上传文件引用转为本地文件路径”；现场 file 类型输入已由平台转换路径。
9. 保存、发布后，在执行页选择串行／并行及上限；运行配置不混入流程定义。

接口说明来自原代码 docstring。发现接口不运行构造器或业务方法；首次调用仍可能因缺依赖或外部服务不可用而失败。支持可用关键字参数调用的同步 Python 接口，暂不支持 async 和位置专用参数。已有 Web/桌面页面不会自动转换成平台展示，需原模块提供数据或图片接口。

## 固定数据和可变对象

固定资源的结果及其对象图应只读，后续解析出另一形态就新增资源或请求参数。平台保存一次、后续使用引用；保留原 Python 类型，不向原业务代码塞代理对象。这也意味着平台无法阻止任意自定义方法原地修改已声明固定的数据。

会改变成员的业务对象放在“实例对象”中，继续保存普通对象快照。大数据应拆成只读资源并让业务对象引用它。锁、连接、页面对象等无法保存时会报错，不能据此承诺任意项目完全零改动。

人工等待保持对象存活；回退复用目标节点结果，普通对象回到目标状态，而已取得固定资源继续保留。并行分支的对象和缓存独立，生成执行的进程上限、失败处理和代数隔离继续生效。

# 组合实例接入

模块维护者继续在原项目中维护公开接口与注释。以下操作由流程编排团队在 NewDiag 完成。

## 三工程示例

在工程页分别登记：

| 名称 | 路径 | 默认模块 |
|---|---|---|
| MockDataService | D:\FILE\Projects\MockDataService | dataclient |
| PlotEngine | D:\FILE\Projects\PlotEngine | dataset |
| JudgeEngine | D:\FILE\Projects\JudgeEngine | judgekit |

工厂留空，解释器使用各工程实际可运行的 Python。PlotEngine 环境需要原有 matplotlib、Tk 依赖，本次未修改三个原项目。

导入 `examples/composed-projects/workflow.json`，保存发布后输入设备、活动及起止时间。平台在开始时获取文件并加载 Dataset，排查时复用内存中的 Dataset，把同一份曲线交给绘图和判断模块。示例默认执行 peak、mean、trend 三条规则，任意触发为是；仅填写 peak 阈值不会关闭另外两条规则。

`workflow-lazy.json` 演示按需加载：开始不获取数据，第一次排查请求 extraDataset 时获取解析并缓存；资源请求的 metrics 默认值与显式同值请求共用缓存。

## 在页面配置

1. 流程属性选择“组合现有工程”。
2. “实例对象”中添加构造器或工厂，配置参数来源；DataClient.root 可选“本次输出目录”。
3. “共享资源”中配置启动或首次使用加载，添加有序调用，指定最终资源结果。Dataset.load 的返回类型选“保留业务对象”。
4. “排查操作”中添加公开方法调用，选择调用目标、参数来源和输出形态；同一调用列表的结果名称必须唯一。
5. 添加图片和文字展示；需要自动分支时选择结果及依据字段。无自动判断时，平台展示结果并等待人工选择。
6. 排查节点选择操作，为 metric、thresholds 等操作参数绑定常量或启动输入。相同操作可供多个节点复用。

接口目录读取代码中的公开函数、类、方法及 docstring。切换模块后点“读取接口”；不会为了发现接口执行构造器。固定值使用 JSON 值，例如 12、"vibration" 或 {"peak":12}，无需 Python 代码。

对象归属工程必须一致。要把 PlotEngine 的 Dataset 交给判断工程，应先调用公开方法输出曲线，而非直接跨工程传 Dataset 对象。图片和数据文件必须输出到平台分配的实例输出目录内。

## 保存恢复和限制

正常调用保留内存对象，人工等待后按现有状态清单恢复。回退读取所选到访的数据版本；回到某资源尚未加载的旧版本时，后续可能再次获取。含窗口、锁或活连接而无法保存的对象继续明确报错，不静默跳过成员或重新取数。

接口实现源码摘要随发布固定，修改业务实现后需重新发布。未安装依赖、私有数据源不可访问和模块导入失败会显示错误，需要在工程运行环境处理。

# 图形独立窗口交付

待办和历史记录共用 DataPresentation，图片与曲线都增加点击放大入口，支持键盘聚焦及 Enter。
图形打开到独立浏览器窗口，可调整窗口大小，提供 25%～400% 缩放、适应窗口；图片额外支持原始尺寸。
默认适应宽高，避免只按宽度缩放导致长图底部被截出视野；放大及原图模式可以滚动查看。

曲线使用打开时的数据副本，图片继续读取原附件；不重跑诊断方法，不改变待办和运行状态。
图形数据只使用会话存储，不写长期本地存储；查看窗口读取后断开 opener。图片链接可单独打开与刷新。
保留图片加载失败提示；窗口拦截、会话图形失效时分别显示重试提示。没有增加依赖或后端接口。

## 检查及实际结果

- 前端类型检查及生产构建通过。

- 在图片链接指向的独立查看页打开 1600×900 PNG，放大按钮切换到 125%；原始尺寸实际渲染为 1600×900；适应窗口后图像完整可见，未出现纵向截断。
